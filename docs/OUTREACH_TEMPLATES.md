# Outreach Templates

Use these templates for direct outreach without spam.

## Template A: Maintainer-to-maintainer collaboration

```text
Hi <name>, I maintain MemoryFeed (local-first memory + MCP).
I noticed your project focuses on <shared area>.
I can build a scoped integration in 24-72 hours and keep it as a clean PR:
- connector/module
- docs + tests
- optional hardening pass

If useful, I can start with a small paid micro-scope first ($25-$75).
```

## Template B: User-facing services post

```text
Paid MemoryFeed help available this week:
- $5 quick triage
- $25 setup/debug
- $75+ feature sprint
Turnaround: same day to 3 days depending on scope.
Open a Paid Integration Request in this repo.
```

## Template C: Follow-up after no response

```text
Quick follow-up on the MemoryFeed integration offer.
I can reduce this to a tiny first step: one concrete patch + tests.
If you share scope and budget, I can estimate in one message.
```
